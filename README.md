Deskripsi Singkat Proyek
Repositori ini berisi implementasi dasar pembuatan dokumen HTML, pengaturan web server lokal dengan Laragon, serta pencatatan request network dokumen web.

Teknologi yang Digunakan
- HTML5
- Web Server**: Apache (via Laragon 5)
- PHP: PHP 8.4
- Version Control: Git & GitHub

Cara Menjalankan Proyek
1. Pastikan Laragon telah terpasang dan service Apache aktif (Start All).
2. Letakkan direktori proyek pada `C:\laragon\www\pemweb-obe`.
3. Buka browser dan akses alamat lokal.

URL Lokal
- URL: [http://localhost/pemweb-obe/](http://localhost/pemweb-obe/)
